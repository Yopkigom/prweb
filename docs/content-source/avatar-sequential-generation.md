# 아바타 순차 생성

간단한 설명: 아바타 생성 최적화로 평균 30fps+ 안정화

## 업무 동기

[Moii](https://www.moii.net/) 프로젝트의 아바타는 최소 18가지의 개별 부위를 조합하여 생성되는 구조입니다.
이로 인해, 일반적으로 사용하는 fbx 모델과 아이템을 조합하는 방식에 비해
리소스 로딩과 정점 연산 비용이 크게 증가하여 화면 렌더링이 멈추는 현상이 발생했습니다.
아바타의 다양한 조합이 가능하다는 장점이 있지만, 사업성의 핵심인 다양한 유저와의 만남을 구현하는 데
가장 큰 단점이 장애물로 작용했습니다.

이 문제를 해결하기 위해 기존 아바타 생성 과정을 비동기 방식으로 변경하고,
앱의 렌더링 성능을 최대한 보장할 수 있도록 최적화를 진행했습니다.

## 업무 성과

아바타의 생성 방식을 앱의 상황에 맞춰 선택할 수 있게 되었습니다.
그룹 대화 같이 10인 이상의 참여자가 필요한 컨텐츠에서
실시간으로 유저들이 참여하는 것에 앱 렌더링 퍼포먼스가 크게 영향받지 않게
서비스를 제공할 수 있었습니다.
